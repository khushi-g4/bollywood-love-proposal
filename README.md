# Forever Begins Today

Cinematic proposal website foundation built with React, TypeScript, Vite, Tailwind CSS, React Three Fiber, Framer Motion, GSAP, Howler, and Lenis.

## Commands

- `npm run dev` — start the local development server
- `npm run build` — type-check and create a production build
- `npm run lint` — run lint checks

## Source structure

- `app/` — application providers and composition
- `components/` — reusable UI, layout, and canvas boundaries
- `config/` — site, theme, and rendering configuration
- `data/` — content data
- `features/` — self-contained proposal sections and interactions
- `hooks/` and `lib/` — reusable application logic and utilities
- `assets/` — local images, audio, and font assets

No cinematic scenes or proposal content are included in this foundation.
